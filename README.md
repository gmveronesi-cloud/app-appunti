# App Appunti

App personale per appunti e PDF su iPad (Swift / SwiftUI / PDFKit / PencilKit), per Swift Playgrounds.
Pacchetto: `Appunti.swiftpm`.

- `Appunti.swiftpm/Libreria/` — Libreria (cartelle reali su iCloud Drive, barra laterale, griglia/lista, selezione)
- `Appunti.swiftpm/Editor/` — editor PDF: tratti con Apple Pencil, lazo, forme, testo, immagini, timer, cattura, vassoio
- `Appunti.swiftpm/Tema/`, `Tastiera/` — stile grafico e tastiera propria
- `docs/` — mockup e regole grafiche; `docs/storico.md` è l'archivio delle consegne
- `STATO.md` — stato, metodo di lavoro e prossimi passi (da leggere per primo)
- `.github/workflows/compila.yml` — compila a ogni modifica al codice su macOS
