# App Appunti

App personale per appunti e PDF su iPad (Swift / SwiftUI / PDFKit / PencilKit).
Pacchetto Swift Playgrounds: `Appunti.swiftpm`.

- `Libreria/` — schermata Libreria (cartelle reali su iCloud Drive)
- `Editor/` — apertura PDF, evidenziatore con Apple Pencil, salvataggio
- `.github/workflows/compila.yml` — compila a ogni modifica su macOS
